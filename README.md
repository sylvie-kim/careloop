# CareLoop
**The AI operations console for sleep clinics and CPAP providers.**

- **Problem:** In the first 90 days of CPAP therapy, many patients quietly struggle and stop. Staff can't easily see who is at risk, why, or who should act next.
- **What it does:** Brings each patient's device data, conversations, and open tasks into one place, and shows staff which patients need attention, why, and what to do next. Staff can ask questions in plain language; numbers are calculated from the clinic's own records, not by the AI.
- **What I did:** Designed and shipped it as a non-developer founder, working with AI coding agents. Built solo since Feb 2026 — 4,300+ commits in a private production repository.
- **Status:** Deployed to production in 2026. Currently running with synthetic demo data only — no real clinics yet.

Built at **SOOMi Health**. The source code stays private because the product handles patient health data.
